# Community Operations Platform

This project is an independent source copy of the bilingual residential-community operations platform.

## Recovery

The `dist/` folder is the deployable static website. The `.openai/hosting.json` file contains the Sites project binding. The project can be opened, edited, or deployed from this folder without relying on chat history.

## Current scope

- Arabic-first responsive administration dashboard
- English-ready interface structure
- Residents and units
- Vehicles and parking
- Visitors and permits
- Maintenance and services
- Facilities and activities
- Reports and settings

Demo values are placeholders until a real community is selected for onboarding.
