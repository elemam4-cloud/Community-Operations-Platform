# Language and Localization Policy

The repository, database seed data, API contract, product documentation, backup archives, and operational records use English as the canonical storage language.

Arabic and other languages are presentation-layer locales. They must be delivered through translated labels, templates, and user-entered content settings rather than by changing the canonical schema, identifiers, API field names, or backup format.

This separation keeps GitHub and Google Drive backups portable, searchable, and consistent while allowing each community to choose its default display language.
