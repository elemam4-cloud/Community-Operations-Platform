# منصة Community Operations Platform — دليل التشغيل الأول

## 1. إعداد المجتمع

1. إنشاء المجتمع واختيار نوعه: `residential` أو `commercial` أو `mixed_use` أو `campus`.
2. إنشاء المباني والوحدات السكنية و/أو الوحدات التجارية.
3. تفعيل الوحدات المطلوبة فقط لكل موقع.
4. إنشاء المستخدمين: الإدارة، التشغيل، الأمن، السكان، ومقدمو الخدمات من خلال نظام الهوية.
5. مراجعة سياسات المجتمع وطريقة التحقق من الدخول.

## 2. تسجيل السكان والمستأجرين

1. إنشاء سجل الشخص أو استيراده.
2. ربط الشخص بالوحدة مع تحديد نوع العلاقة.
3. تسجيل السيارات وبطاقات الدخول عند الحاجة.
4. إضافة عقد الإيجار وجدول الأقساط إذا كانت الوحدة مؤجرة.
5. مراجعة تفضيلات قنوات الإشعارات للمستخدم.

## 3. التشغيل اليومي للدخول

1. إصدار التصريح المناسب للساكن أو الزائر أو الخادمة أو عامل الصيانة أو مندوب التوصيل.
2. يقوم الأمن بالتحقق من التصريح وتسجيل الدخول أو الخروج.
3. يطبق النظام قواعد الوقت والملكية والسياسات حسب إعدادات المجتمع.
4. يظل المسار اليدوي متاحًا عند تعطل جهاز خارجي أو انقطاع الشبكة.
5. يسجل النظام زيارة فعلية منفصلة عن التصريح، بحالات: متوقع، دخل، خرج، أو ملغى.

## 4. تشغيل المواقف

1. تعريف المواقف المشتركة أو الخاصة أو المقيدة بوحدة معينة.
2. اختيار طريقة التخصيص: ثابتة أو بالحجز أو أولوية الوصول.
3. تخصيص الموقف أو السماح بالمطالبة به بعد التحقق من علاقة المستخدم بالوحدة.
4. استقبال حالة الإشغال من الموظفين أو الحساسات أو الكاميرات.
5. عرض الحالات: شاغر أو مشغول أو غير معروف دون تغيير بيانات الملكية.

## 5. الصيانة والتواصل

1. ينشئ الساكن أو موظف التشغيل طلب الصيانة.
2. تقوم الإدارة بالتعيين ومتابعة سجل الحالات.
3. ينشر مركز المعلومات إعلانًا أو تنبيهًا أو فعالية أو إشعار صيانة.
4. تصل الرسالة إلى الجمهور المحدد عبر القنوات المفعلة للمستخدم.
5. يمكن وضع الرسائل والمستندات والطرود والبريد المسجل في صندوق الوحدة الرقمي.

## 6. الإيجارات والمدفوعات

1. إنشاء عقد إيجار للوحدة السكنية أو التجارية.
2. إضافة أقساط شهرية أو سنوية.
3. تسجيل القسط كمستحق أو مدفوع أو متأخر أو معفى.
4. تشغيل مهمة التذكير للأقساط القريبة والمتأخرة.
5. ربط مزودي البريد أو SMS أو WhatsApp عند الحاجة من خلال طبقة التكامل فقط.

## 7. الأمان والاستعادة

- كل عملية تغيير يجب أن تكون قابلة للتدقيق.
- تعطيل الوحدة يخفي مساراتها دون حذف بياناتها.
- تصدير قاعدة البيانات قبل أي ترحيل أو تعديل بنيوي.
- تشغيل اختبارات Worker والتذكيرات وقابلية النقل قبل كل إصدار.
- حفظ مفاتيح الإنتاج وأسرار مزودي الخدمات خارج المستودع وSites.

## ملاحظة المصطلحات

المسارات التقنية وأسماء الحقول مثل `leases` و`visits` و`unit-mailbox` تبقى باللغة الإنجليزية في الدليلين لضمان التطابق مع GitHub وواجهة API.
